# Nivel de Conocimiento en Redes

Este directorio organiza el aprendizaje de redes de datos de forma progresiva.

## Niveles de aprendizaje

### 🔹 Básico
- Concepto de red
- Tipos de redes
- Uso de las redes

### 🔹 Intermedio
- Topologías de red
- Medios de transmisión
- Dispositivos de red

### 🔹 Avanzado
- Modelo OSI y TCP/IP
- Protocolos de red
- Configuración básica

### 🔹 Práctico
- Diseño de redes
- Simulación en Packet Tracer
- Diagnóstico de red

## Objetivo
Desarrollar competencias en instalación, configuración y análisis de redes.
